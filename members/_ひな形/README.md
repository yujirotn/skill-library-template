## おすすめのスキル

- 【スキル名】を【どんな場面】で使っています。【どんな作業が楽になったか】が気に入っています。

このフォルダを `members/<自分の呼び名>/` として使います。スキルは `skills/<スキル名>/SKILL.md` に置き、必要な付属ファイルも同じスキルのフォルダに入れます。[見本](../見本/) も参考にしてください。

`SKILL.md` は上下の `---` で囲んだ `name` と `description` から始めます。名前はフォルダ名と同じ半角英小文字・数字・ハイフンにし、説明は使いどころが分かる一文にすると一覧で読みやすくなります。
